# My Brand Multi-page website (HTML & CSS only)

## Project overview

This is a fully responsive multi-page website built using only HTML & CSS. It is designed for school projects and demonstrates modern web design principles.

## Files Included

- index.html - home page
- about.html - about page
- services - services page
- contact - contact page
- enquiry - enquiry form page
- style.css - external stylesheet

## Features

- Responsive design (mobile-friendly)
- Sticky navigation bar
- Hero section with animation
- Grid-based service cards
- Styled enquiry form
- Hover effects and transitions

## Technologies used

- HTML5
- CSS3

## How to use

- Download all files into one folder
- Open index.html in your browser
- Navigate through pages using the menu

## Learning outcomes

This project demonstrates:

- Website structure using multiple pages
- Linking pages together
- External CSS usage
- Responsive layout
- Basic UI/UX design principles
